# Interview Questions Portal

A modern web application for managing and displaying interview questions and answers.

## Features
- Admin can add, edit, and manage categories (menu items) and questions/answers.
- Public users can only view questions/answers.
- Editable categories: HTML, CSS, JS, Advanced HTML, Advanced TS, Advanced JS, Angular, TS, Node, Camunda, and more.
- Visually appealing, colorful, trendy, and professional UI.
- Responsive design for desktop and mobile.

## Tech Stack
- Frontend: React (with Material UI for design)
- Backend: Node.js (Express)
- Database: SQLite (lightweight, file-based)
- Authentication: Simple admin login

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Admin login credentials are set in the backend `.env` file.

## Folder Structure
- `/client` - React frontend
- `/server` - Node.js backend

---

This project is designed to help users prepare for interviews by providing categorized, up-to-date questions and answers. Admins can easily manage content and categories.
